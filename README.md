# Picross — Японские кроссворды

Логическая головоломка Picross (nonogram) — закрашивайте клетки по числовым подсказкам и собирайте картинки. 

## Стек

| Технология | Назначение |
|------------|------------|
| **Vue 3** | Фреймворк, Composition API |
| **Vite** | Сборка и dev-сервер |
| **Vue Router** | Маршрутизация |
| **Pinia** | Хранение прогресса (миры, уровни, время, звёзды) |
| **SCSS** | Стили |
| **Lucide Vue Next** | Иконки |
| **canvas-confetti** | Конфетти при победе |

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
